Background

Mi trabajo reúne claridad, estructura y expresión, entendiendo la forma no solo como una apariencia sino como una manera de pensar. Creo composiciones visuales que comunican antes de ser decodificadas racionalmente, donde la función matemática y la sensibilidad conviven de manera natural. Mi formación en diseño industrial define este enfoque, dotando a cada proyecto de un equilibrio de intención y rigurosa simplicidad.

Trayectoria & Concepto

Concibo el mundo como un museo inagotable. Haber vivido y trabajado en tres países ha expandido mi perspectiva sobre el diseño y la conexión con equipos multidisciplinarios. Me definen frecuentemente como minimalista tanto en el diseño como en la palabra; elijo lo esencial en mis gráficos para otorgar espacio al significado profundo. Mi fascinación por la geometría pura, el cosmos y los sistemas orgánicos recorre cada una de mis creaciones.

Cómo publicar y actualizar este sitio en GitHub Pages

1

Descarga el paquete del repositorio listo

El archivo ZIP que he generado contiene la estructura limpia: index.html, carpeta assets/ con las fotografías en alta resolución y el archivo README.md.

2

Crea un nuevo repositorio en GitHub

Ve a github.com/new, nómbralo por ejemplo mi-portfolio (o <tu-usuario>.github.io) y márcalo como Público. Sube todos los archivos descomprimidos directamente arrastrándolos a GitHub o mediante git push.

3

Activa GitHub Pages con 1 clic

En tu repositorio de GitHub, entra a Settings > Pages. En la sección Build and deployment, selecciona:

  • Source: Deploy from a branch
  • Branch: main / Folder: / (root)
  • Haz clic en Save.

¡En menos de 60 segundos tu sitio estará online en: https://<tu-usuario>.github.io/mi-portfolio/!

4

¿Cómo actualizar proyectos y fotos fácilmente?

No necesitas compilar nada con Node ni instalar programas. Toda la información vive en un objeto JavaScript simple en el archivo index.html (o data.js). Para agregar un proyecto nuevo:

// 1. Sube tu nueva foto a la carpeta assets/mi-foto.jpg
// 2. En index.html agrega un bloque al arreglo PROJECTS:
{
  id: "mi-nuevo-trabajo",
  num: "07",
  title: "Nuevo Proyecto de Diseño",
  category: "Data viz",
  year: "2026",
  client: "Cliente Internacional",
  image: "assets/mi-foto.jpg",
  tools: "Illustrator, Python",
  concept: "Descripción del concepto...",
  process: "Herramientas utilizadas..."
}

Haces commit directo desde la web de GitHub y tu portafolio se actualizará automáticamente en vivo.
